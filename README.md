# RevDash

Tablero abierto para moto con Android Auto. Reemplaza el tablero de fábrica de una TVS Apache RTR 160 4V
(2026) por una pantalla propia: arranca con la llave mostrando velocidad, marcha, modo y testigos, y da
paso a Android Auto inalámbrico del celular.

Es el proyecto hermano de [RevScope](https://github.com/santiquiroz/revscope) (telemetría OBD2 en el
celular): cada uno funciona solo y, juntos, comparten datos por Bluetooth.
